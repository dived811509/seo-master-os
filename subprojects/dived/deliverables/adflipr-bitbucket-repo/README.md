# Adflipr E-Commerce Shopify & WooCommerce Integration Kit

Official open-source integration helper repository for connecting online stores with the [Adflipr E-Commerce Marketing Automation OS](https://adflipr.com/).

## Overview

This repository contains API integration examples, webhook listeners, and catalog sync helpers for e-commerce store owners using Shopify, WooCommerce, and custom platforms.

## Installation & Setup

1. Clone this repository:
   ```bash
   git clone https://bitbucket.org/adflipr/adflipr-shopify-integration.git
   ```
2. Configure your Adflipr API Key in `.env`:
   ```env
   ADFLIPR_API_KEY=your_api_key_here
   ADFLIPR_STORE_URL=https://adflipr.com
   ```
