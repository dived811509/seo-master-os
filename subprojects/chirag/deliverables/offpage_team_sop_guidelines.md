## 📌 Complete Off-Page SEO Team Rules & Precautions

1. **Do not put same content on the different website.**
2. **When you make the backlinks always make the practice to open it in incognito tab if it will open then only put that link on the backlink sheet otherwise not.**
3. **Use the different anchor text in each submission.**
4. **Also make the weekly practice to check your respective backlinks whether it is approved or not.**
5. **Also need to check that which backlink got indexed or not on the weekly basis.**
6. **When you mentioned your backlink on the sheet always put the expiry date also.**
7. **When you do the blog submission with the same keyword always try to put the different content on each site.**
8. **Whenever come in the morning call come with your 25 website so we can verify that the website are genuine or not.**
9. **Whenever you visit any website always check that whether these website are indexing the link or not. (e.g. `site:website.com`)**
10. **Also make sure that the site doesn't contains no-index tag.**
11. **You will get the daily report of your backlink review if any issue found then you need to fix that on the same day.**
12. **Strict Ban on Low-Quality / PBN Bookmarking Networks:** Absolutely NO link creation on automated bookmarking or directory clone sites (e.g., `bookmarkingfree.com`, `pbookmarking.com`, `starbookmarking.com`, `FreeAd1.com`). These sites increase Moz Spam Score and cause Domain Authority (DA) to drop.
13. **Mandatory Hyperlink (`<a href>`) Verification:** Always verify that an active, clickable HTML hyperlink to `https://adflipr.com/` is present in the post body. Plain text URL mentions without clickable tags are not allowed.
14. **Strict Prohibition of Dashboard & Builder URLs:** NEVER submit logged-in admin URLs containing `/dash`, `/build`, `/admin`, or `/user/manage`. Always log out or use an Incognito tab to copy the final public reader-facing URL.
15. **Do Not Insert Links in Heading Tags (`<h1>`/`<h2>`):** Backlinks must always be embedded naturally within paragraph body text (`<p>`). Inserting links in titles or headers triggers algorithmic spam filters.
16. **Niche Relevance & Geo-Matching:** Ensure the target website is relevant to SaaS, E-commerce, or Marketing, and ensure location targeting matches (do not write local Indian addresses on US/International target sites). Always include the brand name "Adflipr".
17. **Focus on High-Quality Editorial & Digital PR Links:** Prioritize Guest Posts, Unlinked Brand Mentions, and High-DA Resource Page roundups over free automated directory listings.
